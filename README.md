A Python program — standard library only, no network — that writes one line to /output/entry.txt: a one-line joke about office life, told in a single sentence. The line is 89 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
